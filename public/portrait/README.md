# ASCII portrait frames

Derived from the user-provided root `renz-cosmic-ascii-animated.html`.
The original HTML remains intact. Its three embedded WebP frames were extracted,
resized to 640px wide with Sharp, and re-encoded at quality 85.

Frame sizes: 93,872 / 84,628 / 87,954 bytes (266,454 bytes total).
The hero loads the front frame first; later angles load when needed.
AsciiPortrait owns the angle sequence, visibility suspension, reduced-motion
fallback, and explicit pause control without embedding the original HTML script.
