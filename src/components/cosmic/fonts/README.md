# Cosmic display font

Unbounded Black, Latin subset, static weight 900. Unmodified WOFF2 sourced from:
`https://github.com/fontsource/font-files/blob/main/fonts/google/unbounded/files/unbounded-latin-900-normal.woff2`

Family and style checked with Next's bundled fontkit reader. File size: 21,112 bytes. OFL license from `google/fonts/ofl/unbounded/OFL.txt` is included alongside the asset. The larger variable TTF used during inspection is not shipped.

Loaded with `next/font/local` in the cosmic preview layout so only the preview and its state gallery use this display face. Body text retains the existing local Inter.
